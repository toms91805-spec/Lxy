# 语音转文字

对着麦克风说话，文字实时出现在窗口里；也可以把识别结果**直接打进任意其他程序的光标处**。
**全程离线运行，语音数据不会离开你的电脑。**

---

## 快速开始

**方式一：直接用打包好的应用（最省事，推荐）**

双击桌面上的 **「语音转文字」** 快捷方式即可打开 —— 它是一个**独立应用**
（`dist\语音转文字\语音转文字.exe`），双击就开、**不经过黑色终端窗口**。

**方式二：从源码运行（想自己改代码，或还没打包时）**

1. 双击 **`安装依赖.bat`**（只需第一次运行，会自动创建虚拟环境并安装依赖）
2. 双击 **`启动程序.bat`** 打开程序
3. 想要方式一那样的独立应用，双击 **`打包成应用.bat`**：
   它会自动安装 PyInstaller、把程序打包成 EXE、复制模型和配套文件，并把桌面快捷方式指向这个 EXE。

**方式三：分享给别人 / 装到新电脑（用安装包）**

双击 **`打包成安装包.bat`**，它会生成 **`发布\语音转文字安装包.zip`**（约 120 MB）。
把压缩包发给别人，对方**解压后双击里面的 `安装程序.exe`**，就会打开安装页面：

- 页面上有完整的**安装须知**（管理员权限、首次启动较慢、SmartScreen 提示、安装位置建议、卸载方式等），建议先读一遍；
- **安装位置可以自定义**：默认装在当前用户的 `AppData\Local\Programs\语音转文字`，
  也可以点「浏览…」换到别的目录（不写系统目录、不需要管理员权限）；
- 可选「在桌面创建快捷方式」「安装完成后立即运行」；安装过程有进度条，随时能取消，
  取消后已复制的文件会保留，重新安装会直接覆盖。

> 安装包里**只带了小模型**，所以压缩包能压到 120 MB 左右，方便网盘 / 微信分享；
> 想要更高的识别精度，让对方在程序里点「下载大模型」即可（大模型 2 GB，不随安装包分发）。

**三种方式都一样：** 等右上角变成 **「模型：已就绪」** 后，点 **「开始识别」**，对着麦克风说话即可。

> 想先确认环境是否正常？双击 **`自检工具.bat`**：它会一次性检查依赖、模型、麦克风、
> 全局热键和权限，并给出「环境正常 / 存在问题」的结论，比直接启动更容易定位问题。

> **为什么要管理员权限？** 微信、记事本、浏览器不需要，但**游戏（如一梦江湖）通常以管理员身份运行**。
> Windows 会拦截「普通权限程序 → 高权限窗口」的模拟输入，导致识别正常、文字却打不进去。
> 以管理员身份运行本程序就能一并覆盖这两种情况。
> 源码方式双击 `启动程序.bat` 时，脚本会自己弹出 UAC 请求提权；
> **打包成应用后**（桌面快捷方式指向 EXE），需要给游戏输入时请**右键 EXE → 以管理员身份运行**。
> 只想日常在微信 / 记事本里用，直接双击即可（普通权限够用）。

## 在其他程序里语音打字（重点）

想在微信、浏览器、Word、记事本等**任意程序**里用说话代替打字：

1. 保持程序在后台运行（窗口可以最小化，别关掉）
2. 确认勾选了 **「把识别结果直接输入到当前光标处（其他程序）」**（默认已勾选）
3. 把光标点进你要输入的地方，然后**按住热键说话，说完松开**（按住说话模式，热键默认是 `F9`，可在界面右上角更换）

- 识别出的文字会**直接出现在你当前光标的位置**，不用切回本程序复制粘贴。
- 热键是**系统级**的，在任何程序里都能用，不需要本窗口处于激活状态。
- **按住才录、松开就停**：松开热键后，程序会把最后一段话定稿并打进光标处，稍等约 0.5 秒即可看到完整文字。
- 松开热键后不用再按任何键，下次想说话再按住即可。
- 文字通过系统输入注入，**不会占用你的剪贴板**，也不会触发输入法候选框。
- 想要「纯记录、不输入到别处」时，把那个勾去掉即可，识别结果只显示在本窗口里。
- 不确定当前「输入方式」在目标程序里管不管用时，点 **「测试输入」** 按钮：程序会倒计时 3 秒，
  你切到目标窗口等着，它就会自动打一段测试文字进去，不用真的说话。

> 中文识别模型（`vosk-model-small-cn-0.22`）已经打包在 `models\` 文件夹里，**开箱即用，全程不需要联网**。
> 如果 `models\` 被删掉，程序会自动重新下载（GitHub 镜像优先，官方站兜底）。

## 让识别更准

准确率主要取决于两件事：**模型大小**和**音频质量**。

### 办法一：换高精度大模型（提升最大）

默认用的小模型（`vosk-model-small-cn-0.22`，42 MB）胜在快、体积小；
官方还有一个高精度大模型 `vosk-model-cn-0.22`（约 1.3 GB），
按官方测试集的**字错率**对比，大约只有小模型的一半：

| 模型 | 体积 | 字错率（越低越准） |
| --- | --- | --- |
| vosk-model-small-cn-0.22（默认） | 42 MB | 23.54 |
| vosk-model-cn-0.22（高精度） | 1.3 GB | 13.98 |

用法：点界面上的 **「下载高精度模型（约 1.3 GB）」** → 下完重启程序即可。
程序会自动检测 `models\` 里有没有大模型，**有就优先用**，不需要改任何配置。

- **优先走镜像，官方站只作兜底**：内置源按实测速度排序为
  `aifasthub.com`（约 **0.6~2.8 MB/s**，目前最稳）→ `hf-mirror.com`（曾经约 4 MB/s，
  但会整站不可达）→ 官方站（国内只有十几 KB/s，1.3 GB 要二十多个小时，基本等于不可用）。
  每个源各自保留断点，互不影响。
- **不做探活，直接按固定优先级依次试**：链路抖动时，一次 1 KB 的小请求经常探不到数据，
  会把明明能跑满速的镜像误判成死源、排到又慢又稳的官方站后面，然后就一直卡在几十 KB/s。
  所以按上面的顺序依次试，真正挂掉的源交给下面的「连续零进展」逻辑几轮就跳过，
  既不用等探活那二十几秒，也不会误伤能用的快源。
- 下载进度会显示 **已下 MB / 总量**、**实时速度** 和 **预计剩余时间**。
  因为总量有 1.3 GB，百分比保留一位小数 —— 前面十几 MB 还不到 1%，所以数字看着小是正常的，
  看 MB 数和速度就知道在不在动。刚开始那半秒还没测出速度，会先显示「测速中…」。
- 下载支持**断点续传**：中途失败、取消或关掉程序，下次点按钮会接着下，不用从头再来。
  重连采用逐步拉长的退避间隔（最长 20 秒一次），断线后自动从断点接着下。
- **判断要不要换源看的是「有没有进展」，不是「花了多久」**：镜像速度会在
  0.5~2.8 MB/s 之间波动，1.3 GB 慢起来要几十分钟；只要断点文件还在增长就继续下，
  只有连续多次重连一个字节都没涨，才换下一个源。所以慢速时不会把正常推进的源误判成失败。
- **随时可以取消**：下载中按钮会变成「取消下载」，点一下就停；已下的部分留着，下次接着下。
- **坏文件会自动清掉**：每次下载前都会检查残留文件，把 0 字节、大小不对、
  不是有效压缩包的坏文件删掉，避免续传一直卡在坏文件上。
- **下载失败后会问你要不要删掉临时文件**：可以保留下来下次续传，也可以直接删掉释放空间。
- 下载期间程序照常能用。
- 代价：启动慢一些、内存占用高一些（约 1～2 GB）。

#### 内置源都下不动？填一个自定义镜像

界面「识别精度」卡片里有一行 **「下载镜像」**，可以直接填自己的加速地址：

- **留空**（默认）：用内置源（aifasthub 镜像 → HF 镜像 → 官方站）。
- **填了**：下载时会**优先尝试**这个地址，内置源作为后备。
  适合公司内网镜像、代理地址，或你手上确认能用的其他镜像。
- 地址要指向 `model-cn.zip`，必须是完整的 `http://` 或 `https://` 链接，例如：
  `https://aifasthub.com/LiangJingyi/vosk-model-cn-0.22/resolve/main/model-cn.zip`
- 填好后会自动记住（写入 `设置.json` 的 `模型镜像`），下次打开还在。

同一行右边的 **「清理下载文件」** 按钮，用来一键删掉 `models\` 里所有没下完的
临时文件（`.part` 和残留的 `.zip`），并告诉你释放了多少空间。
输入框下面会实时显示当前有没有待续传的临时文件、有多大。

- 也可以自己下载，解压后确保目录是 `models\vosk-model-cn-0.22\`，重启程序即可：
  镜像 <https://aifasthub.com/LiangJingyi/vosk-model-cn-0.22/resolve/main/model-cn.zip>（快）、
  <https://hf-mirror.com/LiangJingyi/vosk-model-cn-0.22/resolve/main/model-cn.zip>（备选）、
  官方 <https://alphacephei.com/vosk/models/vosk-model-cn-0.22.zip>（慢）。

### 办法二：打开「增强音频」（默认已开）

界面「识别精度」一行里的 **「增强音频（降噪+增益）」**，做两件事：

- **高通滤波**：滤掉 85 Hz 以下的低频轰鸣（风扇声、桌面震动、电流声）。
  这些声音对识别没帮助，却会干扰特征提取，环境嘈杂时影响很明显。
- **自动增益**：麦克风音量偏小时把声音抬到合适电平（只放大、不衰减）。
  声音太小是中文识别出错的主要原因之一。

> 如果开了之后反而变差（例如麦克风本身底噪很大），把勾去掉即可，下次开始识别时生效。

### 其他能立刻改善的细节

- **离麦克风近一点**（10～20 厘米），说话清楚、别太快。
- **环境安静**：关掉风扇、音乐，或用带指向性的耳麦。
- 在顶部下拉框里**选对麦克风**，别选到摄像头或显示器自带的那个。
- 说话时看一眼**音量条**：跳动幅度很小说明麦克风增益太低，可在系统声音设置里调高。
- 模型本身**不会自动加标点**：可以打开 **「自动标点」**（按停顿自动补），
  或用 **「口述标点」** 说「逗号 / 句号」来补（见下面的「文本处理」一节）。

## 识别语言与声调（可选项）

### 勾选可识别的语言（中 / 英 / 日，可多选）

界面 **「识别语言与精度」** 卡片里的 **「可识别的语言」** 是一组**复选框**，可以**同时勾选多种**语言
（默认只勾中文）。识别时程序会把同一段语音同时喂给每个已勾选的模型，再挑**最可信**的一个作为结果，
所以不用事先告诉它你说的是哪种语言 —— **自动判断**。

| 可识别的语言 | 轻量模型 | 高精度模型 |
| --- | --- | --- |
| 中文（默认勾选） | 42 MB | 1.3 GB（可选下载） |
| 英语（美式） | 40 MB | 128 MB（可选下载） |
| 英语（英式） | 40 MB | —（只有轻量模型） |
| 日语 | 48 MB | —（只有轻量模型） |

- 勾选后，程序会**自动下载并加载**所选语言的模型；进度显示在右上角「模型：」处，
  下载完自动生效，不用重启。
- **至少保留一种语言**：取消最后一个勾选时会被自动挡回（否则没有模型可用）。
- 勾得越多、每段语音要跑的模型越多，识别会更吃 CPU；日常「中文 + 英语」两种足够。
- 下载源：中文优先 GitHub 分片镜像，其余语言走 HF 镜像（`hf-mirror.com`），官方站兜底；
  同样支持断点续传、自动重连和「取消下载」。
- 各语言的模型**各自独立存放**（`models\vosk-model-...`），互相不覆盖，
  取消勾选再勾回来即用、不用重下。
- 选择会记进 `设置.json` 的 `languages`（列表）；旧版本的 `language` 单选键仍能读取。
- 高精度模型也按语言区分：某语言装了大模型时程序**自动优先用大模型**；
  某语言没有高精度模型时，「下载高精度模型」按钮会自动跳过它。

### 声调标注（仅中文，可开关）

Vosk 的中文模型只输出汉字、**不带声调**，选哪个字完全由模型自己决定。
「识别语言与精度」卡片里的 **「声调标注」** 勾上后，会在识别结果**下方补一行带声调的拼音**：

```
你好，世界
nǐ hǎo，shì jiè
```

- 用途：一眼看出有没有**同音字写错**（「在 / 再」「的 / 得 / 地」「是 / 事」这类），
  再配合「替换词典」把常错的词纠正过来。
- **只补注音，不改动识别结果本身**：复制、保存、注入到其它程序的内容仍是原来的汉字，
  拼音那一行只显示在本窗口里。
- **只在勾了中文时可用**：取消勾选中文（只识别英语 / 日语）时这个勾会自动置灰，并提示「当前语言没有声调概念」
  （这些语言没有声调，Vosk 输出的就是它们自己的文字）。
- 默认开启；不需要就点掉这个勾（写入 `设置.json` 的 `tone`）。
- 依赖 `pypinyin` 库（已随程序打包）。源码运行若缺库，界面会提示「缺少 pypinyin 库，无法标注」，
  双击 `安装依赖.bat` 即可补上。

## 文本处理：标点与纠错

### 口述标点（默认已开）

说到这些词，程序会自动把它换成对应符号，不用手动补标点：

| 说的词 | 变成 | 说的词 | 变成 |
| --- | --- | --- | --- |
| 逗号 | ， | 句号 | 。 |
| 问号 | ？ | 感叹号 / 叹号 | ！ |
| 冒号 | ： | 分号 | ； |
| 顿号 | 、 | 省略号 | …… |
| 破折号 | —— | 左括号 / 右括号 | （ ） |
| 双引号 | “” | 换行 / 回车 / 换段 | 换行 |

比如说「今天天气不错**逗号**我们出去走走吧**句号**」，得到的就是「今天天气不错，我们出去走走吧。」

> 说这些词时要说清楚、连在一起（别把「逗号」说成「逗 号」）。
> 不需要这个功能，把 **「口述标点」** 的勾去掉即可。

### 自动标点（默认已开）

懒得口述「逗号 / 句号」时，可以让程序**按说话停顿自动补标点**：

- 说完一句**停一下**再说下一句，程序会在两句之间补上标点 —— 不用刻意说「句号」。
- **按住热键说话（按住说话）同样有效**：松开热键后隔一会儿再按住说下一句，
  这段「松手到下次开口」的静音也算作停顿，照样会补标点。
- **停顿长短决定断句方式**：
  - 停 **≥ 1.8 秒**（一句话说完了）→ 补 **。** 或 **？** / **！**
  - 停 **≥ 0.8 秒**（句中换口气）→ 补 **，**
  - 更短的停顿 → 什么都不加，文字直接连起来
- **「说话 / 停顿」的判断跟着你的麦克风音量自动调整**，安静麦克风和高增益麦克风都能判准，
  不需要手动设阈值。
- **符号按句意挑**：句尾带「吗 / 呢 / 么」或「什么 / 怎么 / 是不是 / 有没有」这类疑问词 → **？**；
  带「啊 / 呀 / 哇」或「太好了 / 加油 / 真棒」这类感叹 → **！**；其余 → **。**
- 上一句**已经带标点**时（比如你自己说了「句号」）不会再补，不会出现「。。」。

> 这是**按停顿和关键词猜的**（模型本身不带标点、也没有语气识别），猜错也只是标点不对，不影响文字本身。
> 不需要就点掉 **「自动标点」** 的勾。它和「口述标点」相互独立，可以只开一个。

### 替换词典（纠错）

有些词模型总认错（人名、地名、游戏名、专业术语），用替换词典一次改好：

1. 点界面上的 **「替换词典」** 按钮
2. 每行写一条 `识别到的词=想要的词`，例如：

   ```
   一梦江户=一梦江湖
   认知=任职
   zhongguo=中国
   ```

3. 点 **「保存」**，**立即生效**，不用重启程序

词典保存在程序目录的 `替换词典.txt`（UTF-8），也可以直接编辑这个文件，重启程序后生效。
以 `#` 开头的行会被当作注释忽略。
处理顺序是**先去空格 → 再转标点 → 最后做替换**，所以词典里也可以写与标点相关的内容。

## 往游戏里打字（以一梦江湖为例）

游戏是特殊情况：一梦江湖这类游戏**以管理员身份运行**，聊天框还是**引擎自绘**的（不是标准输入框）。
Windows 的 UIPI 机制规定 **SendInput 和 PostMessage 都只能注入到「权限同级或更低」的进程**，
所以普通权限的程序**无论如何都送不进字**。必须下面两步都做到：

### 第一步：让本程序也以管理员身份运行（必须）

1. 关掉**所有**「语音转文字」窗口（同时开多个时，只有一个能占用热键）
2. 双击桌面 **「语音转文字」** 快捷方式 → UAC 弹窗点 **「是」**
3. 界面上如果出现**黄底提示条**，说明当前还是普通权限，注入不进去

### 第二步：把「输入方式」逐个试一遍

下拉框里共 4 种方式，按顺序试，哪种能出字就固定用哪种：

| 输入方式 | 什么时候用 |
| --- | --- |
| 模拟按键（通用） | 记事本、浏览器、微信、Office —— **默认值**，常规程序用这个 |
| 消息注入（WM_CHAR） | **换成游戏聊天框时先试这个** |
| IME 消息（游戏常用） | 上一条没反应就试这个，游戏常走输入法通道 |
| 剪贴板粘贴（Ctrl+V） | 前两条都不行时用；会短暂占用剪贴板，用完自动还原 |

测法：点进游戏聊天框 → 按住热键说一句话 → 松开 → 看字有没有进去；没进去就换下一种再试。
嫌说话试太慢，可以直接点 **「测试输入」**：点完切回游戏，3 秒后它会自动把测试文字打进去。

> 如果 4 种方式全都无效，说明该游戏的反作弊拦截了所有外部输入，这种情况本程序无能为力。

## 常见问题

**Q：不确定环境有没有问题 / 程序启动异常，怎么快速排查？**

双击 **`自检工具.bat`**。它会依次检查：Python 版本、依赖库、识别模型、麦克风设备、
全局热键是否被占用、当前权限和注入接口，最后给出「环境正常」或「存在失败项」的结论。
失败项旁边会写明该怎么处理（比如「双击安装依赖.bat」「关闭占用 F9 的软件」）。

**Q：提示「打开麦克风失败」怎么办？**

1. 检查是否选对了麦克风设备（下拉框里换成名字带「麦克风 / Microphone」的那一项）
2. 打开 `Windows 设置 → 隐私和安全性 → 麦克风`，确认「允许桌面应用访问你的麦克风」已开启
3. 关掉其他正在占用麦克风的软件（会议软件、录音软件等）

**Q：识别出来的字不准 / 有空格？**

- 程序会自动去掉中文字之间的空格。中英夹杂时英文单词之间会保留空格。
- 这个模型（`vosk-model-small-cn-0.22`）体积小、速度快，适合实时场景，但准确率不如大模型。环境安静、离麦克风近一些，效果会明显变好。
- 模型**不会自动加标点**：打开 **「自动标点」**，说完一句停一下，程序就会按停顿自动补「，/。/？/！」；
  也可以打开 **「口述标点」**，说「逗号 / 句号 / 换行」来补标点（见上面的「文本处理」一节）。
- 某些词总认错（人名、地名、游戏名），用 **「替换词典」** 一次改好，改完立即生效。

**Q：识别结果里总有几个词是错的，能自动纠正吗？**

能。点界面 **「替换词典」**，每行写一条 `识别到的词=想要的词`，保存后**立即生效**，
不用重启。例如 `一梦江户=一梦江湖`。详见上面的「文本处理：标点与纠错」一节。

**Q：在高分屏 / 缩放 150% 的屏幕上界面会很小吗？**

不会。程序会读取系统 DPI，把窗口尺寸和字号一起放大，保证在 125% / 150% / 200% 缩放下
文字清晰、控件不重叠（是原生清晰渲染，不是被系统拉伸放大）。

窗口定位按**桌面工作区**算，也就是已经扣掉了任务栏：高度取「控件实际需要」和「工作区的 88%」中较小者，
再在工作区里垂直居中，所以底部（音量条、隐私提示）不会被任务栏压住，四周也留出桌面留白。
如果觉得窗口太大或太小，直接拖动窗口边缘调整即可（最小尺寸已限制）。

**Q：想换成深色界面 / 窗口位置老是变？**

- 换主题：点顶栏右侧的主题按钮即可在**深色 / 浅色**间切换，主窗口和「替换词典」窗口会一起换，选择会记住。
- 窗口大小和位置：调整后关闭程序会自动记住，下次启动**原样还原**；若窗口被挪到屏幕外，程序会自动拉回屏幕内。
  想恢复默认布局，删掉 `设置.json` 里的 `window` 一行（或整个文件）即可。

**Q：想让它更准一点？**

见上面的 **「让识别更准」** 一节。最有效的是换高精度大模型：点界面上的
**「下载高精度模型（约 1.3 GB）」**，下完重启程序即可 —— 程序会自动检测并优先使用它，
不需要改任何配置。其次确认 **「增强音频（降噪+增益）」** 是勾上的（默认已勾）。

**Q：模型下载失败（网络问题）？**

小模型：程序会先走 GitHub 镜像（<https://github.com/jimy7945/vosk-model-cn>，国内速度快），失败再试官方站
<https://alphacephei.com/vosk/models/vosk-model-small-cn-0.22.zip>（国内经常连不上）。
也可以自己下载官方 zip，解压后确保目录结构为 `models\vosk-model-small-cn-0.22\`，再重新启动程序。

大模型：优先 aifasthub 镜像，其次 HF 镜像，失败再回退官方站；按固定优先级依次试，不做探活。**内置源都下不动时，在「识别精度」卡片
的「下载镜像」里填一个你能用的加速地址即可**（见上面「内置源都下不动？填一个自定义镜像」）。
下载失败后程序会问你要不要删掉临时文件：想接着续传就保留，想释放空间就删掉。

**Q：下载高精度模型时进度一直是 0% / 速度很慢 / 中途断了？**

- **0% 是错觉**：大模型总量 1.3 GB，要下到十几 MB 才跳到 1%。界面现在会显示
  「已下 XX MB / 1294 MB，约 XX KB/s，约 X 分 X 秒后完成」，看 MB 数和速度就能确认它一直在动。
  刚点下去的半秒内还没测出速度，会先显示「测速中…」，属正常。
- **速度慢**：程序按固定优先级依次试源，正常会走 aifasthub 镜像（约 0.6~2.8 MB/s，
  1.3 GB 约十几分钟到半小时）。如果长期只有几十 KB/s，说明前两个镜像都没连上、正在用官方站，
  可以取消后重试（会重走一遍优先级），或改用自己的镜像地址。
- **中途断了**：会自动从断点重连续传（重试间隔逐步拉长），只要还在下就不会放弃；
  只有连续多次重连都毫无进展才换源，全部源都没救才停下来报错。已下的部分会保留，下次点「下载」接着下。
- **速度忽快忽慢**：这是链路本身在波动（同一镜像实测过 0.5 MB/s 和 2.8 MB/s），不是程序问题。
  多开连接也没用（实测 4 连接只比单连接快 12%），瓶颈在链路不在连接数，所以耐心等它下完即可。
- **不想下了**：下载中那个按钮会变成「取消下载」，点一下就停，已下的部分会保留，下次点「下载」接着下。
- **想彻底清干净**：点「识别精度」卡片里的「清理下载文件」，会删掉所有没下完的临时文件并告诉你释放了多少空间。
- 嫌慢也可以手动下载，镜像链接见上面「让识别更准」一节；下完解压成 `models\vosk-model-cn-0.22\` 即可。

**Q：按住热键没反应？**

- 程序必须**保持运行**（窗口可最小化，但不能关闭）。
- 该热键可能被别的软件占用了。界面右上角会红字提示「注册失败」，此时在右侧下拉框里**换一个热键**（比如 `F8`、`F10`、`Ctrl+F9`）即可，不用重启程序。
- 热键是**单键**（或 `Ctrl+F9` 这类组合键），程序运行期间会被本程序独占，其他软件收不到它。如果某个游戏／软件本身要用同一个键，请换一个热键或先关闭本程序。
- 必须**一直按住**热键才会录音；点一下马上松开，几乎录不到声音，属于正常现象。
- 少数游戏 / 以管理员身份运行的程序会拦截模拟输入，需要以管理员身份运行本程序才能输入进去。

**Q：语音输入到某些程序没反应？**

先做一个判断：**文字有没有出现在「语音转文字」程序自己的窗口里？**

- **本窗口里有字，目标程序里没字** → 识别没问题，是「注入」被挡了。最常见的原因是权限不对等：
  对方程序（尤其是一梦江湖、剑网 3 这类游戏）以**管理员身份**运行，而本程序是普通权限，
  Windows 的 UIPI 机制会直接丢弃这种跨权限的模拟输入。
  **解决：关掉本程序，改用桌面「语音转文字」快捷方式启动（会请求管理员权限）。**
- **本窗口里也没字** → 是识别本身没跑起来，检查麦克风设备、热键是否注册成功（右上角有没有红字）、
  以及说话时音量条有没有跳动。

其余说明：文字是通过系统输入注入的，绝大多数程序（记事本、浏览器、Office、微信、QQ、各类聊天框）都支持。
个别自绘界面的程序或游戏可能不接受这种注入方式，属于对方程序的限制。

**Q：状态栏提示「文字没能送进目标程序」？**

这是程序**自动帮你判断**出来的：它识别到了文字（本窗口里有字），但一个字都没能注入到目标程序。
说明问题不在识别，而在「注入」，按顺序试：

1. 换一个 **「输入方式」**（游戏聊天框优先试「消息注入」或「IME 消息」）。
2. 点 **「测试输入」**，切到目标程序看测试文字进不进得去，快速判断是哪种方式有效。
3. 目标程序若是游戏／以管理员身份运行，**本程序也必须以管理员身份运行**（用桌面快捷方式启动）。

**Q：提示「没有检测到麦克风」？**

1. 确认麦克风已插好、系统能识别到，然后点界面的 **「刷新」** 重新扫描设备。
2. 打开 `Windows 设置 → 隐私和安全性 → 麦克风`，允许桌面应用访问你的麦克风。
3. 关掉可能独占麦克风的软件（会议、录音软件等），再点「刷新」。

**Q：正在说话时突然提示「麦克风没有音频数据」或「识别引擎出错了」？**

这是程序检测到异常后**主动停下来**，避免界面一直假装在聆听：

- **麦克风没有音频数据**：连续 3 秒收不到音频，通常是麦克风被拔掉、被别的程序独占，或系统里该设备被禁用。处理好后重新点「开始识别」即可。
- **识别引擎出错了**：识别线程遇到了意外错误，已自动停止。点 **「打开日志」** 看 `运行日志.txt` 里的具体原因；重启程序一般就能恢复。

**Q：游戏里按住热键说话，一个字都没进去？**

**看上面的「往游戏里打字（以一梦江湖为例）」一节**，核心就两件事：本程序要以管理员身份运行、
「输入方式」要换成「消息注入」或「IME 消息」。补充排查：

1. 是否**同时开了多个**「语音转文字」窗口 —— 只有一个能占用热键，其余的会红字提示注册失败，请只留一个。
2. 游戏聊天框是否已经**点进输入状态**（光标在输入框里闪烁）。
3. 点一下 **「测试输入」**，切回游戏看测试文字进不进得去 —— 能进说明只是识别/热键的问题，进不去就是注入被挡。
4. 若 4 种输入方式全部无效，说明该游戏的反作弊拦截了所有外部输入，只能改用游戏自带语音。

**Q：为什么说完一句话要停顿一下才出字？**

识别器在**你停顿的地方**才会把临时结果「定稿」，然后才把这段文字打进光标处。
说话时正常断句、稍作停顿，输入会更连贯。

**Q：为什么不用联网的识别？**

离线的好处是：断网可用、响应快、隐私好。代价是需要一次性下载模型。

## 技术实现

- **音频采集**：[sounddevice](https://python-sounddevice.readthedocs.io/)（PortAudio），16 kHz / 单声道 / int16
- **语音识别**：[Vosk](https://alphacephei.com/vosk/) 离线引擎，流式输出临时结果 + 确认结果
- **重采样**：[soxr](https://python-soxr.readthedocs.io/) —— 当麦克风不支持 16 kHz 时自动转换
- **音频增强**：85 Hz 二阶高通滤波（去低频轰鸣）+ 带底噪门控的自动增益（只放大、不衰减），
  在重采样之后、送入识别器之前处理，滤波器状态跨音频块保留以免出现咔哒声
- **模型选择**：启动时自动检测 `models\`，有高精度大模型就优先用，否则用默认小模型
- **模型下载**：多源回退 —— 高精度大模型不做探活，直接按固定优先级（aifasthub → HF 镜像 → 官方站）依次尝试，并支持自定义镜像地址（界面可填）；
  放弃某个源看的是「连续多次重连零进展」而非时间预算，
  所以慢速但在推进的源不会被误判失败；
  带断点续传（逐步拉长的退避重连）、大小校验和 zip 完整性校验；镜像包内部目录名与官方不一致（如 `model-cn/`）时自动改名对齐；
  自动清理 0 字节 / 大小不符 / 非压缩包的损坏残留，界面实时显示已下 MB、速度与预计剩余时间，
  下载中可一键取消（取消同样保留断点），失败后可选择是否删除临时文件
- **界面**：Python 内置 tkinter
- **全局热键**：Win32 `RegisterHotKey`（后台线程消息循环，无需管理员权限、无第三方依赖），热键可在界面切换
- **按住说话（PTT）**：`RegisterHotKey` 吞掉热键事件（目标程序收不到这个键），再用 `GetAsyncKeyState` 轮询判断按下／松开 —— 两条路径都不用键盘钩子，避免与带反作弊的游戏冲突
- **文字注入**：Win32 `SendInput` + `KEYEVENTF_UNICODE`，直接发送 Unicode 码点，绕过输入法、不占用剪贴板
- **单实例保护**：命名互斥体（`CreateMutexW`），防止多开互相抢热键、覆盖日志
- **开机自启动**：写入当前用户注册表 Run 项（`winreg`），普通权限、可随时取消
- **异常兜底**：识别线程崩溃、麦克风掉线、注入失败都会被捕获并主动停止、在状态栏给出可操作的提示
- **结果后处理**：去中文空格 → 口述标点转换（长词优先匹配）→ 用户替换词典，三步依次作用于最终结果
- **自动标点**：在原始音频上做轻量 VAD（自适应底噪门限），量出每段语音之前的停顿；停顿随识别结果一起送到界面，
  按停顿长短断句（≥1.8 秒补 。/？/！，≥0.8 秒补 ，），再按句尾关键词判断语气挑符号
- **高分屏适配**：读取系统 DPI，按比例放大窗口尺寸、字号和间距，避免在高分屏上又小又挤
- **界面主题**：参照 TraeWork 的视觉风格 —— 浅灰画布 + 纯白面板 + 极浅描边 + 单一靛蓝强调色
  （`#4b3fe3`），文字近黑、次级文字中性灰；浅色 / 深色两套配色集中定义成调色板，
  切换时用同一套调色板重建界面，主窗口与「替换词典」窗口共用同一配色，
  选择写入设置、下次启动沿用；Win11 下窗口本体带圆角、深色主题时标题栏一并变深
- **窗口记忆**：关闭时把窗口尺寸和位置写入 `设置.json`，启动时还原；
  还原前用桌面工作区做校验，越界或尺寸异常会自动收回屏幕内，避免窗口「跑到看不见的地方」
- **应用打包**：用 PyInstaller 打包成独立 EXE（`--windowed`，不弹终端窗口），
  模型与资源文件随包分发，双击即可运行、无需装 Python
- **环境自检**：`自检工具.bat` 调用 `自检.py`，逐项检查依赖 / 模型 / 麦克风 / 热键 / 权限并给出结论
- **模型路径**：Vosk 读不了中文路径，程序会自动建一个 NTFS 目录联接映射成纯 ASCII 路径再加载

数据流：`麦克风 → sounddevice 回调 → 音频队列 → 识别线程（Vosk）→ 结果队列 → 界面刷新 / 注入到当前窗口`

界面线程和识别线程通过 `queue.Queue` 通信，识别不会卡住界面；热键线程也通过同一个队列把按键事件交给界面线程处理。

## 开源与许可

本项目以 [MIT License](LICENSE) 开源，欢迎 Issue 与 Pull Request。

- **仓库只包含源码与脚本**：识别模型（`models/`）、虚拟环境（`.venv/`）、打包产物（`dist/`、`发布/`）以及本机运行数据（`设置.json`、`运行日志.txt`）都已通过 `.gitignore` 排除。
- **模型不随仓库分发**：首次运行会自动下载中文小模型；其他语言和更高精度的模型可在程序内按需下载。
- **从源码运行**：克隆仓库后双击 `安装依赖.bat`，再双击 `启动程序.bat` 即可。
- **二次分发**：修改后如需打包，运行 `打包成应用.bat`（独立 EXE）或 `打包成安装包.bat`（可分享的安装包）。

使用的第三方组件：

- [Vosk](https://github.com/alphacep/vosk-api)（Apache-2.0）—— 离线语音识别
- [sounddevice](https://github.com/spatialaudio/python-sounddevice)（MIT）—— 麦克风采集
- [soxr](https://github.com/dscerberus/soxr)（LGPL-2.1）—— 音频重采样
- [NumPy](https://numpy.org/)（BSD-3-Clause）
- [pypinyin](https://github.com/mozillazg/python-pinyin)（MIT）—— 声调标注
- 界面使用 Python 标准库 `tkinter`
